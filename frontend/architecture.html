Frontend Layer

  • • React / Next.js
  • • Tailwind CSS
  • • Leaflet + OpenStreetMap
  • • User & Admin interfaces

Backend Layer

  • • Spring Boot REST API
  • • Spring Security (JWT Auth)
  • • Business logic & validation
  • • File handling (videos/images)

Database Layer

  • • PostgreSQL
  • • Users, Sessions, Detections
  • • Potholes & Complaints
  • • Status history tracking

AI / ML Layer

  • • Python + YOLO
  • • OpenCV (frame extraction)
  • • GPS timestamp matching
  • • Called via API / microservice

Main Data Flow

  1. Citizen uploads road video + GPS track through the website
  2. Frontend sends files to Spring Boot REST API
  3. API stores files and creates a recording session in PostgreSQL
  4. Python service extracts frames (OpenCV) and runs YOLO detection
  5. Detections + GPS-matched coordinates are saved in the database
  6. Citizen reviews detections, confirms, and creates complaints
  7. Admin views live data, verifies reports, and updates complaint status
